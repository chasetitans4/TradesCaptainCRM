# Monitoring and Alerting

## Instrumentation
- OpenTelemetry, APM integration
- Structured JSON logs with correlation IDs

## Health Metrics
- CPU, memory, disk, DB connections, queue depth

## App Performance
- Request rate, error rate, p95/p99 latencies per endpoint
- Webhook success/failure counts

## Business KPIs
- Leads, conversion rate, MRR, churn, SMS usage/overage

## Alerts
- Thresholds and anomalies with PagerDuty/Slack/Email
- Attach runbooks to alerts

## Logging
- Retention policy and searchable dashboards
